개인정보 처리 안내 — 한국어 개인판 보안 패치

문자·앱 알림·사용자가 켠 통화 알림은 사용자가 활성화한 규칙에 따라 선택한 전송 채널로 전달됩니다. Webhook, Telegram, 이메일 등의 수신 서비스에는 해당 메시지와 전송에 필요한 정보가 전달됩니다. 외부 서비스의 보관 정책은 해당 사업자 정책을 따릅니다.

자동 공인 IP 조회와 전화번호 지역 조회를 제거했습니다. 통화 전달과 기기 주소록 이름 조회는 선택 기능으로 복원했으며 기본 꺼짐입니다. 해당 기능을 켤 때 권한을 요청합니다. 예약·메시지 기반 자동 작업도 기본 꺼짐이며 지원하는 전달/알림/규칙 동작만 실행합니다. 위치·블루투스·원격 HTTP 서버·FRP는 계속 비활성화합니다.

규칙, 전송 계정 정보와 메시지 전달 기록은 기기 내 앱 전용 저장소에 저장됩니다. 전체 데이터베이스를 별도로 암호화하는 기능은 제공하지 않습니다. Android 자동 클라우드 백업을 허용하지 않으며 재부팅 후 잠금 해제 뒤 동작합니다. 설정 백업은 사용자가 선택한 파일에 비밀번호로 암호화해 저장합니다. 선택한 저장 제공자가 클라우드이면 그 서비스에도 암호화 파일이 저장될 수 있습니다. 비밀번호를 잊으면 복원할 수 없습니다.

HTTP 전송 채널은 HTTPS와 시스템 인증서 검증을 사용합니다. 외부 평문 HTTP와 자동 리다이렉트를 차단합니다. 기기 내부 localhost 연결만 평문 예외입니다. 이메일·문자 등 다른 채널은 해당 방식의 보안 특성을 따릅니다.

릴리스 앱의 자체 진단 로그 출력을 중지했습니다. 메시지 전달 기록 화면은 유지됩니다. 모든 라이브러리와 실제 네트워크 트래픽을 전수 검증했다는 보증은 아닙니다.

문자 및 알림 접근 권한은 기능에 필요하며 민감한 정보에 접근할 수 있습니다. 신뢰하는 수신지와 필요한 규칙만 사용하세요. Play Protect 경고가 사라진다는 보장은 없습니다.
