## 로그 시간 한국어 수정 — 기본 versionCode 59

- 라이브러리에 하드코딩된 중국어 상대 시간 함수를 앱의 한국어 포맷터로 교체.
- 전달 로그·자동 작업 목록·문자 조회·통화 조회에 적용.
- 비활성 채널 오류에 사용 스위치를 켜고 저장하라는 해결 방법 표시.
- 채널 테스트는 사용 스위치와 독립적으로 전송됨. 테스트 성공만으로 실제 규칙 전달이 활성화된 것은 아님.
- XML 외에 상대 시간 호출 및 화면 자산도 현지화 검사에 포함.

## 소스 중국어 제거 — 기본 versionCode 60

- Kotlin 소스의 중국어 주석을 제거하고, 남은 구형 설정 호환값은 Unicode 이스케이프로 보존.
- 라이브러리나 외부 서비스가 보낸 중국어 오류는 전달 로그와 공통 오류 토스트에서 한국어 안내로 대체.
- 현지화 검사가 모든 앱 소스 파일의 중국어 문자를 실패 처리.
## ABI 업데이트 호환 수정 — 기본 versionCode 300061

- universal과 ABI별 APK가 서로 다른 versionCode를 사용해 업데이트가 다운그레이드로 거부될 수 있던 문제를 수정했다.
- 두 배포 APK에 하나의 단조 증가 versionCode를 사용한다. 기존 universal·arm64 설치본 위에서 어느 배포 파일로도 업데이트할 수 있다.
- 빌드 수집 검사는 두 APK의 versionCode가 같지 않으면 실패하도록 보완했다.

## 기능 유지·권한 정리 — versionCode 300063

- 기존 전체판의 문자·통화·앱 알림, Telegram·Webhook 및 다른 전송 채널, 자동 작업, 암호화 백업·복원을 유지한다. 경량판 300062에서 빠졌던 기능도 다시 사용할 수 있다.
- 문자 수신에 쓰지 않는 READ_SMS와 광범위한 QUERY_ALL_PACKAGES·GET_INSTALLED_APPS 선언을 제거한다. 앱 선택 목록은 실행 아이콘이 있는 앱을 조회하며, 목록에 없는 앱은 패키지명을 직접 입력할 수 있다.
- RECEIVE_SMS와 알림 접근은 문자·앱 알림 전달에 필요하므로 유지한다. 토스 또는 Play Protect의 경고 해제는 실제 기기에서 확인해야 한다.

## 두 가지 빌드 — Light 300064 / 표준판 300065

- Light는 선택한 앱의 알림을 Telegram Bot 또는 HTTPS Webhook으로 직접 전달한다. 문자·통화 접근과 원본 알림 삭제 기능을 포함하지 않는다.
- 표준판은 300063의 전체 기능을 유지하고, Light 위에 다시 업데이트할 수 있도록 versionCode를 300065로 올린다. 민감 권한이 필요한 기능 때문에 Play Protect 또는 금융 앱 차단이 계속될 수 있다.
- 두 빌드는 같은 앱 ID·서명을 사용하므로 동시에 설치되지 않는다. Light 설치 후 표준판 복귀는 300065를 사용한다.
