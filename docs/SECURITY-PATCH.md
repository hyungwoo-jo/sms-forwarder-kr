# 최신 기능 복원판

기본 versionCode 58에서는 통화 전달·기기 연락처 이름 조회·예약/메시지 자동 작업과 암호화 파일 백업/복원을 복원합니다. 선택 기능은 기본 OFF입니다. 자동 작업은 문자 발송·선택한 채널의 알림 전송·규칙/채널/작업 상태·알람·재전송만 허용합니다. 위치·블루투스·원격 HTTP 서버·FRP·SMS 원격 명령은 계속 비활성화합니다. 자동 외부 IP/전화번호 조회 제거·HTTPS 검증·외부 HTTP/리다이렉트 차단 정책은 유지합니다.

백업은 AES-256-GCM, 무작위 salt/IV와 비밀번호 파생 키를 사용하며 Android 파일 선택기로 저장합니다. 암호화만으로 짧거나 재사용한 비밀번호의 위험이 없어지는 것은 아닙니다. 비밀번호는 저장하지 않습니다. 복원은 현재 설정과 전달 기록을 교체하며 신규 암호화 백업만 지원합니다. 기기에서 파일 선택기와 실제 복원 동작은 DEVICE_PENDING입니다.

공식 참고: [Android 암호화](https://developer.android.com/privacy-and-security/cryptography), [파일 선택기](https://developer.android.com/training/data-storage/shared/documents-files).

## 이전 축소판 설명 (versionCode 57)

# 보안 패치

개인정보 처리 안내 — 한국어 개인판 보안 패치

문자와 앱 알림은 사용자가 활성화한 규칙에 따라 선택한 전송 채널로 전달됩니다. Webhook, Telegram, 이메일 등의 수신 서비스에는 해당 메시지와 전송에 필요한 정보가 전달됩니다. 외부 서비스의 보관 정책은 해당 사업자 정책을 따릅니다.

자동 공인 IP 조회와 전화번호 지역 조회를 제거했습니다. 위치·통화·연락처 조회, 블루투스 제어, 원격 HTTP 서버, 자동 기기 제어 및 FRP 기능은 이 배포판에서 지원하지 않습니다. 기존 설정을 가져와도 다시 활성화되지 않습니다.

규칙, 전송 계정 정보와 메시지 전달 기록은 기기 내 앱 전용 저장소에 저장됩니다. 전체 데이터베이스를 별도로 암호화하는 기능은 제공하지 않습니다. Android 자동 클라우드 백업을 허용하지 않으며 재부팅 후 잠금 해제 뒤 동작합니다. 사용자가 선택한 공유·내보내기 기능은 별도입니다.

HTTP 전송 채널은 HTTPS와 시스템 인증서 검증을 사용합니다. 외부 평문 HTTP와 자동 리다이렉트를 차단합니다. 기기 내부 localhost 연결만 평문 예외입니다. 이메일·문자 등 다른 채널은 해당 방식의 보안 특성을 따릅니다.

릴리스 앱의 자체 진단 로그 출력을 중지했습니다. 메시지 전달 기록 화면은 유지됩니다. 모든 라이브러리와 실제 네트워크 트래픽을 전수 검증했다는 보증은 아닙니다.

문자 및 알림 접근 권한은 기능에 필요하며 민감한 정보에 접근할 수 있습니다. 신뢰하는 수신지와 필요한 규칙만 사용하세요. Play Protect 경고가 사라진다는 보장은 없습니다.

Play Protect: 스토어 등록만으로 모든 경고가 해제되지는 않습니다. 문자·알림 권한, 사이드로드 경로, 앱 평판·서명 및 검사 결과에 따라 경고가 발생할 수 있습니다. 실제 경고 유형은 기기에서 확인해야 합니다.

공식 안내: https://developers.google.com/android/play-protect/warning-dev-guidance

Webhook: 전송 채널에 HTTPS 서버 URL을 등록하고 앱 알림 규칙에서 WORKS 패키지를 선택한 뒤 그 채널을 연결합니다. 인증 헤더와 요청 본문 형식은 서버 요구에 맞춥니다. URL을 리다이렉트되는 주소 대신 최종 수신 주소로 설정하세요. 문자 규칙도 같은 채널로 보낼 수 있습니다.

기기 미연결: 실제 문자 수신, WORKS 앱 선택·알림 수신, 재부팅·절전 및 Play Protect는 DEVICE_PENDING입니다.
