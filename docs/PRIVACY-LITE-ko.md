# 알림 전달 Light 개인정보 처리방침

최종 수정: 2026년 9월 29일

알림 전달 Light(`com.hwserve.smsforwarder`)와 알림 릴레이(`com.hwserve.notifyrelay`)는 사용자가 선택한 앱의 알림을 사용자가 지정한 Telegram 채팅 또는 HTTPS Webhook으로 전달하는 앱입니다.

## 접근하는 정보와 목적

- Android 알림 접근을 허용하면 운영체제는 앱에 기기 알림을 읽을 수 있는 권한을 줍니다. 앱은 최근 알림의 **패키지명**을 설정 편의를 위해 기기에 저장합니다. 전달 기능을 켰을 때에는 사용자가 입력한 패키지명과 일치하는 알림의 제목·본문을 읽어 지정한 대상으로 전송합니다.
- 사용자가 입력한 앱 패키지명, Telegram Bot 토큰·채팅 ID·토픽 ID, Webhook 주소·헤더·본문 설정, 마지막 전송 결과는 기기의 앱 전용 저장공간에 저장합니다. 알림 전달 Light를 이전 정식판 위에 업데이트한 경우 이전 데이터베이스에서 단일 활성 전송 설정을 읽어 입력란을 채울 수 있습니다. 이때 전달은 자동으로 켜지지 않습니다. 알림 릴레이는 이전 앱 데이터베이스를 읽지 않습니다.

## 외부 전송과 보관

- Telegram 직접 전송을 켜면 알림 제목·본문과 채팅 ID가 사용자의 Bot 토큰을 이용해 `api.telegram.org`로 전송됩니다.
- Webhook 전송을 켜면 알림 제목·본문과 원본 앱 패키지명이 사용자가 입력한 HTTPS 주소로 전송됩니다. 사용자가 입력한 헤더 또는 템플릿도 요청에 포함될 수 있습니다.
- 앱 개발자가 운영하는 중계 서버로 알림 내용을 전송하지 않습니다. 전송 대상에서 데이터를 보관하거나 처리하는 방식은 해당 서비스의 정책과 사용자가 운영하는 서버 설정을 따릅니다.
- 앱 자체의 알림 내용 보관·검색 기능은 없습니다. 설정과 마지막 전송 결과는 앱을 삭제하거나 앱 데이터를 지울 때까지 기기에 남습니다. Android의 앱 백업은 사용하지 않도록 설정했습니다.

## 사용자 선택

앱 화면에서 전달 기능 또는 개별 전송 경로를 끌 수 있습니다. Android 설정에서 이 앱의 알림 접근을 철회할 수 있습니다. 앱 데이터를 삭제하면 기기에 저장된 설정도 삭제됩니다.
